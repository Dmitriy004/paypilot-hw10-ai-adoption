# L11 OpenAI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Відтворювана демонстрація трьох mutation scores без вигаданих людських вимірів.

**Architecture:** Незмінний upstream FX, 7 baseline functions, 12 frozen mutants, одна OpenAI генерація з явним allowlist. Review та rewritten не змінюють green generated comparator.

**Tech Stack:** Python 3.12, pytest 9.2.0, pytest-cov 7.1.0, stdlib urllib Responses API.

**Spec:** `docs/superpowers/specs/2026-11-13-l11-openai-design.md`
