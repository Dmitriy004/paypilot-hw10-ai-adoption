# AI Adoption Impact Report — L11: два набори на одному модулі

**13.11.2026 · PayPilot FX · мандат Ship it.** Це власна локальна демонстрація, **не коректний експеримент «людина без асистента проти AI»**: за рішенням користувача baseline і рев'ю підготовлено асистентом, Claude замінено на OpenAI. 40/45 хв — планові припущення, не заміри та не підтверджені середні значення. Самостійний baseline і людський таймер, яких вимагає курс, не виконані. Не видавати цей варіант за повну відповідність лабораторному протоколу.

Джерело: [публічний кіт d6c471a](https://github.com/TarasFedorenkoFTV/paypilot-l11-eval/tree/d6c471a79e3bb4da33756c6e1026d3366f98faf5). `app/`, `.claude/settings.json`, requirements і mutation runner незмінні. Стенд і попередні ДЗ не чіпали. Кінець сторінки курсу повторно не прочитано: браузерний інструмент повертає `timeoutMs`; основою виконання є раніше прочитані кроки й офіційний README/шаблон кіта.

`mutants.toml`: 12 одиничних змін, по 3 у кожному дослівному класі; freeze `6c58594` до генерації `e7c77a6` і до всіх mutation reports. `python tools/run_mutants.py --check` підтвердив застосовність кожного find рівно один раз. Список не змінювався після freeze; лише тимчасові копії файлів змінює upstream runner.

| Клас | ID | Зміна |
| --- | --- | --- |
| значення тіру | A-01/02/03 | помилковий спред відповідно tier2/tier1/tier3 |
| межа EUR 1 000 | B-01/02/03 | `<` замість `<=` (усі тіри); ліміт tier2 999; ігнорування previous usage |

Це додаткові безкоштовні локальні запуски, не нові незалежні експерименти.

## 3. Критерії рев'ю і промпт

Шість критеріїв зафіксовані у `prompts/review-criteria.md`, commit `6c58594`: незалежний еталон, конкретність перевірки, чесна межа, незалежність від часу/порядку, змістовне ім'я, новизна щодо baseline та раніше прийнятих G. Exceptions/properties оцінюються з відповідними винятками курсу.

Дослівний слабкий промпт у `prompts/generation-prompt.md`:

```text
Згенеруй unit-тести для модуля app/engines/fx.py. Поклади їх у tests/generated/test_fx_generated.py.
```

OpenAI отримав **тільки** цей текст і повний `fx.py` з роздільником назви файлу. Точний body — `reports/openai-generation/request.json`; без tools, історії чату, policy, baseline, mutants чи критеріїв. `.claude/settings.json` не змінено, але він **не** обмежує Responses API; ізоляцію тут задає allowlist у `tools/generate_openai.py` та збережений payload. У generated є policy imports — це читання таблиць під час локального pytest, не доказ, що модель отримувала таблиці у запиті.

## 5. Generation Review Log

Повний [журнал](review-log.md): G-01..G-11, verdict/criterion/reason/action/minutes на кожну початкову функцію, включно з прийнятими та original-red G-06. Прийнято 3/11, відхилено 8/11 = 72.73%; найчастіше — oracle (5), assertion level (2), novelty (1). G-03 прийнятий лише як вузька перевірка безкоштовного quote/метаданих, не тарифів чи точного курсу. Нові accepted класи — невідомі валюти, невідомий тип переказу, USD→EUR no-spread/поля валют і тіру.

Переписано 3/8 rejected — **асистентом**, не авторським ручним рев'ю: R-01 (G-06) правильний override + законний free контроль; R-02 (G-07) конкретні часткові суми; R-03 (G-09) усі поля словника та точність. `tests/rewritten/test_fx_rewritten.py`, 3 функції / 4 cases green. Вони **не входять** до manual/generated/all. Відхилені green функції лишилися в generated comparator; score не є оцінкою accepted-only набору.

Реальні людські хвилини на review/rewrite невідомі. Планові 45 хв не розподілені на вигадані індивідуальні записи. Весь original suite після доповнень: 34/34 PASS, із них 9 infrastructure, які також не входять до mutation comparator (`reports/full-original.xml`).

| Набір | Команда | Звіт |

Той самий committed список `6c58594`, uncommitted=false; код прогонів `1616a96`. Між наборами змінювались тільки pytest paths — не original FX, список, інтерпретатор або параметри мутацій.

| Клас (по 3 мутанти) | Baseline | Generated | Union |
| --- | --- | --- | --- |
| значення тіру | 3/3 | 0/3 | 3/3 |
| межа EUR 1 000 | 3/3 | 1/3 | 3/3 |
| арифметика | 3/3 | 2/3 | 3/3 |

| fx.py line coverage | 34/45 = 75.56% | 45/45 = 100% | не вимірювали |

Вціліли baseline/union: **D-01, D-02, D-03**. Generated: **A-01, A-02, A-03, B-01, B-02, C-01, D-01, D-02, D-03**. Generated kills: **B-03, C-02, C-03**; це не нові kills понад baseline, додаткова користь union 0/12 на цьому списку.

Причина: generated тарифні еталони переважно читають ту саму policy; жодного точного EUR1000 boundary. C-01 лишає співвідношення final/gross узгодженим, і слабкий self-derived еталон не помічає неправильний gross. G-09 перевіряє ідемпотентність round(v,6), яку задовольняє й round(v,2), та ітерує лише наявні keys. Поле previous usage не перевіряється. **Класу, де generated сильніший за baseline, тут немає.**

Це повний перепис зафіксованих 12 штучних змін, не випадкова вибірка банківських багів: довірчий інтервал production detection не оцінюється. Одна генерація моделі не визначає розкид результатів інших генерацій. Більше рядкове покриття тут не означає кращого захисту від помилкових комісій.

За бажанням перевірити продуктивність потрібен новий незалежний human baseline із таймером, не перезапис цього результату.

## 8. Робочий висновок

За Ship it використовувати модель для чернеток тестів і нових класів входів, але не автоматичного схвалення тарифів: вимоги, точні суми/межі та поля результату потребують незалежного перегляду. На цьому конкретному списку 100% покриття generated супроводжується лише 3/12 виявлених змін; union не додав жодної до 9/12 baseline. Не робимо з цього універсальний рейтинг моделей.

За Zero regulatory risk той самий generated-only набір не є підставою дозволяти реліз фінансових розрахунків. Повторити висновок після зміни моделі, контексту (наприклад, явного додавання вимог), самого FX або набору мутацій — новий протокол і прогноз до прогонів. Поточний ризиковий вердикт фінального проєкту ця вузька демонстрація не скасовує.

## 10. Відтворення і статус

Локальні коміти, без push або LMS. Команди нижче не потребують ключів і нічого не генерують повторно:

```text
python -m pip install -r requirements.txt
python -m pytest
python tools/run_mutants.py --check
python tools/run_mutants.py --set manual
python tools/run_mutants.py --set generated
python tools/run_mutants.py --set all
```

Перевірка на чистому локальному clone та незалежне final review ще виконуються; їхній фактичний proof буде додано окремо. Це лабораторна демонстрація, не підготовлене/відправлене ДЗ; homework-only generic template і формальний Impact Report зараз не заявляються готовими.
