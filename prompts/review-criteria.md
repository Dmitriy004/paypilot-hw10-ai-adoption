# Критерії до генерації

| Критерій | Приймаємо | Відхиляємо |
| --- | --- | --- |
| Оракул | конкретне незалежне число з вимог | очікуване з функції, policy-констант або monkeypatch таблиць |
| Рівень assertion | конкретне значення (L1–L2) | лише isinstance / is not None / > 0 |
| Крайовий випадок | рівно ліміт EUR 500/1000/5000 або чесно не boundary | назва/коментар boundary, а вхід далеко від межі |
| Незалежність | без порядку/годинника/спільного mutable state | залежить від порядку або datetime.now() |
| Ім'я | називає правило | test_quote_1 / test_works |
| Новизна | новий клас входу або поле щодо baseline і вже прийнятих G | той самий клас і перевірка з іншим числом |

Для exceptions/properties оракул N/A; boundary лише якщо тест заявляє межу. Для кількох assertions головне правило з імені. Параметризована функція — один G-ID. Кожній функції verdict, criterion, reason, action, minutes; незаміряні хвилини позначати незаміряними, не вигадувати.

Generated після freeze не редагувати, крім видалення original-red функцій окремим комітом. Відхилені green лишаються в comparator; useful rewrites окремо, не в manual/generated/all. Ці критерії не входять до OpenAI payload.
